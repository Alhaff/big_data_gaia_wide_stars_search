# Докази повного запуску

Сюди копіюються результати запуску на повному датасеті (`--input /data/raw`), бо `output/` і `spark-events/` не входять у git.
Як саме копіювати: `docs/run_guide.md`, крок 8.

- `spark-events/` - журнал подій Spark. Переглянути: покласти файл у `spark-events/` проєкту і відкрити History Server (http://localhost:18080).
- `plans/` - `explain("formatted")` кожного етапу (план до запуску, фінальний план після AQE є в журналі, вкладка SQL).
- `metrics.json` - час етапів, кількість записів, відкинуті рядки, розподіл ключів.
- `experiment/` - журнали й таблиця замірів експерименту (розділ 7).
